# 🏦 Java ATM Console Application

> **Learning Status:** 🚧 Practice Project (Work in Progress)

A secure and interactive console-based ATM banking simulation program built using **Core Java**. This project was created to practice programming fundamentals, control structures, methods, and basic logic handling.

---

### 💡 Features
- 🔐 **Secure PIN Authentication:** Includes a 3-attempt limit security check before accessing the ATM menu.
- 💰 **Current Balance Inquiry:** Check account balance in real-time.
- 💵 **Deposit System:** Allows positive amount deposits with balance updates.
- 💸 **Withdrawal System:** Validates sufficient balance and positive amounts before processing.
- 📜 **Transaction History:** Tracks and displays recent deposits and withdrawals.
- ℹ️ **About & Exit Options:** Interactive menu navigation.

---

### 🛠️ Tech Stack & Concepts Used
- **Language:** Java
- **Programming Concepts:** 
  - Methods & Modular Design
  - Control Flow (`while` loops, `switch-case`, `if-else`)
  - Scanner Input Handling
  - String Manipulation for History Tracking
